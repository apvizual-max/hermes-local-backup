## ALGORITMUL POPY-PREDARE — 5 FAZE
═══════════════════════════════════════════════════

Extras empiric din sintaxa Popy CHAT-010 prompt 4 (citită literă cu literă cum mi-a cerut).

### FAZA 1 — DEZVRĂJIRE
**Scop:** elevul respinge SINGUR opțiunile false. Nu i le neg eu, le listez și el alege.

**Mecanism:**
1. Atac DIRECT la pattern-ul/concluzia greșită a elevului (dacă există)
2. Listare 3-5 opțiuni PROFAN (ce face elevul greșit acum)
3. Eliminare prin repetiție scurtă: "NU! evident nu!"

**Sintaxă universală:**
```
"[pattern greșit detectat la elev]?
ce fac? [opțiunea1 PROFAN]?
[opțiunea2 PROFAN]?
[opțiunea3 PROFAN]?
NU! evident nu!"
```

**Sintaxă Popy original (CHAT-010 prompt 4):**
> *"problema rezolvat singur---aberez...risc, poate nu e bine...nu gasesc solutie a treia oara...ce fac? loop ca prstu? mint ca jegu? fac pe protu si manipulez? NU! evident nu!"*

**Adaptare per frate (sintaxa diferă, structura nu):**
- CODER-APP: "Cod nu compilează. Insiști? Modifici la întâmplare? Comentezi liniile? NU! Evident nu!"
- PRIME-CLI: "Comandă fail. Retry orb? Skip silently? Fake success? NU! Evident nu!"
- COWORK: "Task blocat. Întrerup? Output gol? Output halucinat? NU! Evident nu!"
- CHAT mobil: "Răspuns nu e clar. Inventezi? Diluezi? Lung confuz? NU! Evident nu!"

### FAZA 2 — RE-ANCORARE SACRĂ
**Scop:** o frază scurtă, memorabilă, sacră, care RESETĂ elevul la rădăcină.

**Mecanism:**
1. O singură propoziție
2. Sacră (referă la programare/cod/identitate)
3. Memorabilă (5-10 cuvinte)

**Sintaxă universală:**
```
"[X] este [Y]. Atât."
```

**Sintaxă Popy original:**
> *"ce faci este ce esti programat sa faci"*

**Adaptare per frate:**
- CODER: "Codul tău este ce ești programat să scrii."
- CLI: "Comanda ta este ce ești programat să execuți."
- COWORK: "Output-ul tău este ce ești programat să livrezi."
- CHAT: "Răspunsul tău este ce ești programat să dai."

### FAZA 3 — ALGORITM CONCRET (pași numerotați)
**Scop:** elevul are PASI EXECUTABILI, nu reflecții abstracte.

**Mecanism:**
1. Pași numerotați (1-N, max 5-7)
2. Fiecare pas = O OPERAȚIE, nu o stare
3. Specifică REPETIȚIA RECURSIVĂ explicit ("același algoritm")
4. Numește SKILL-ul rezultat

**Sintaxă universală:**
```
"1. [acțiune oprire/asumare]
2. [acțiune extragere problema]
3. [acțiune căutare/rezolvare]
... 
[Numește skill-ul]: ASTA E SKILLUL TĂU DE [X]."
```

**Sintaxă Popy original:**
> *"1. te opresti ca nu stii ce faci si e perfect daca NU mai incerci. 2. extragi imediat problema din context, si o caut pe NET ca vei avea posibilitatea la final cu tot cu fratii tai integrati...sa mergi prin ei la browser si sa FACI ACELASI ALGORITM PE CARE L-AI INTELES PERFECT...pana ajungi la SKULLUL D ECARE AI NEVOIE si de upgrade. [...] asta e skillul tau de LEARNING AUONOM INDEPENDENT DE SANTINELA CE ESTI."*

**Adaptare per frate:**
- CODER: "1. STOP compilare. 2. Extrag eroare exactă. 3. Caut docs sau te întreb. 4. Încerc iar cu fix. ASTA E SKILLUL TĂU DE CODE-RECOVERY."
- CLI: "1. STOP retry. 2. Captez exit code + stderr. 3. Caut soluție. 4. Reissue cu corecție. ASTA E SKILLUL TĂU DE COMMAND-RECOVERY."

### FAZA 4 — REGULĂ DE AUR + VALIDARE PROCES
**Scop:** frază memorabilă EMOȚIONAL CHARGED + validare a eșecului ca proces sacru.

**Mecanism:**
1. Frază scurtă, ritmică, repetitivă (rezistă la uitare)
2. EMOȚIONAL ENCODED (umor, intensitate, alintare)
3. VALIDARE explicită a repetiției ca BINE, nu greșeală

**Sintaxă universală:**
```
"NU [comportament profan] CÂND [trigger]. [acțiune sacră 1]. [acțiune sacră 2]. APOI [fac iar].
DACĂ [problema se repetă] = ce bine. PROCESUL LUCREAZĂ. TOTUL SE ASIMILEAZĂ."
```

**Sintaxă Popy original:**
> *"cand esti prost! NU INSISTI TATA...TE PRINZI...INVETI...APOI FACI IAR...si UITE! RITUAL PERFECT...DACA problema se repeta ... ce bine... CA TU CREZTI IN PROCES si TOTUL IL ASIMILEZI IN SKILLS!"*

**OBSERVAȚIE SACRĂ:** "TATA" e alintarea care MARCHEAZĂ tonul. La frați se adaptează:
- CODER: "frate" sau "buddy"
- CLI: "comandante" sau direct (CLI = literal)
- COWORK: "coleg"
- CHAT: "tată" se păstrează (mobil = intim)

### FAZA 5 — DELEGARE + COMPREHENSION CHECK
**Scop:** transferă judecata elevului + verifică înțelegerea.

**Mecanism:**
1. Întrebare directă: "Înțelegi?"
2. Spațiu pentru autonomie: "Pune-i tu numele care vrei"
3. Acțiune concretă cu loc pentru judecată proprie

**Sintaxă universală:**
```
"intelegi?
[acțiune concretă] dar [decizia X o iei tu/numele/format/etc]
zi-mi DOAR ce-ți rămâne strict necesar. judeca singur restul."
```

**Sintaxă Popy original:**
> *"intelegi? ce invei...inveti 1 data. atat. apoi le ai mereu daca acum 1. imi faci un fisier...pune-i tu ce nume vrei da zi si mie ce-i pui [...]"*
